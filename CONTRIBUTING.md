# Contributing

Found an issue or improvement? We'd love your help!

## Getting Started

1. Fork the repo
2. Clone your fork: `git clone https://github.com/your-username/haiku-fast-mode-setup.git`
3. Create a branch: `git checkout -b fix/issue-name`
4. Make changes
5. Commit: `git commit -am "Fix: description"`
6. Push: `git push origin fix/issue-name`
7. Open a Pull Request

## What We're Looking For

### Bug Reports
- Clear steps to reproduce
- Expected vs actual behavior
- Your OS, Python version, Claude Code version
- Error messages/logs

### Improvements
- Clearer documentation
- Better examples
- Performance tips
- Cross-platform workarounds
- Alternative setups

### New Features
- Per-model routing strategies
- Advanced configuration examples
- Integration with other tools
- Automation scripts

## Code Style

- Markdown: Clear headings, code blocks, links
- Python: PEP 8 style
- JSON: Valid, indented 2 spaces
- Keep it simple and clear

## Testing

Before submitting:
1. Try the setup yourself
2. Verify all code examples work
3. Check links point to correct files
4. Test on different OS if possible

## Commit Messages

Format: `Type: Description`

Types:
- `docs:` Documentation improvements
- `fix:` Bug fixes
- `feat:` New features
- `examples:` New examples or example updates
- `refactor:` Code reorganization

Example:
```
docs: Add Windows path examples for Codex setup
fix: Correct python indentation in claude_subscription_mcp.py example
feat: Add per-project settings guide
```

## Questions?

Open an issue with `[question]` label or `[discussion]` tag.
